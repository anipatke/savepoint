# O-041: Scenario evals for the skills

## Outcome

Each workflow skill has a durable set of at least three written scenarios that state an input and the expected behaviour. Planners and checkers re-walk the set against revised text, and the end-of-Goal retrospective reuses it.

## Why

O-034 walked its scenarios once, inside Task evidence. Without a kept set, each review rebuilds its baseline, and nothing shows which rules agents depend on most.

## Success Conditions

- Detailed when this Objective is next.

## Boundaries

**In scope:** written scenarios (for example REPLAN REQUIRED re-entry, a waived Task Check reaching the Full Objective Check, worktree-lane limits, and a checker refusing to repair), where they live, how they are re-walked, and content tests that keep them in step with the skills.

**Out of scope:** live agent runs, multi-model testing, and automated eval tooling.
